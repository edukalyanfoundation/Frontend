# Edukalyan Frontend Root Directory

This directory represents the Edukalyan Foundation Web Platform UI modules:

- `public/` - Edukalyan Foundation Public NGO Website (Landing, Courses, About, Blog, Verification).
- `user/` - Student User Portal & Dashboard.
- `admin/` - NGO Administrator Command Center & UGC Registrations console.

The frontend application code is located in `apps/web` with Vite, React 19, TypeScript, and Tailwind CSS.
